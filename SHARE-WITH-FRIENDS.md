# 📦 Share Ninja Runner Extension with Friends

## Method 1: Direct VSIX Installation

### For You (Creator):

1. Share the file: `ninja-runner-0.0.1.vsix`
2. Send it via email, cloud storage, or messaging

### For Your Friends:

1. Download the `ninja-runner-0.0.1.vsix` file
2. Open VS Code
3. Press `Ctrl+Shift+P` (Command Palette)
4. Type: "Extensions: Install from VSIX"
5. Select the downloaded `.vsix` file
6. Extension will be installed and ready to use!

## Method 2: Command Line Installation

Your friends can install via terminal:

```bash
code --install-extension ninja-runner-0.0.1.vsix
```

## Method 3: GitHub Releases

1. Upload the `.vsix` file to your GitHub repository releases
2. Friends can download from: https://github.com/akhil-prajapati/ninja-runner/releases
3. Install using method 1 or 2 above
